# colorist

An AI-driven color grading tool for my guitar videos: same room, same lamp, one approved look per lamp color. Not a general tool.

Needs an Apple Silicon Mac with [Homebrew](https://brew.sh) and [mise](https://mise.jdx.dev). Run `./setup.sh` to install the tools.

See [AGENTS.md](AGENTS.md) for how it works.
